🤖 IoT / Embedded
2024 ✓ Completed

Smart Parking System Using Sensors

🏛️ Engineering Project — Adichunchanagiri Institute of Technology (AIT)

Designed and implemented a real-time IoT-based smart parking management system using ultrasonic and IR sensors mounted at each parking bay. The system continuously polls sensor states via an ESP8266 Wi-Fi module, pushes occupancy data to a web dashboard, and also shows slot status on a 16×2 LCD display.

Key Features & Outcomes

  • 🟢 Real-time slot occupancy detection (green = free / red = occupied)
  • 📡 ESP8266 Wi-Fi module for wireless data transmission
  • 🖥️ 16×2 LCD display for on-site status readout
  • 📊 Web dashboard showing live availability count per zone
  • ⏱️ ~60% reduction in time wasted searching for parking
  • 💾 C (Embedded) firmware with interrupt-driven sensor polling

Technology Stack

  • Arduino Uno
  • ESP8266 Wi-Fi
  • HC-SR04 Ultrasonic
  • IR Proximity Sensors
  • C (Embedded)
  • LCD 16×2 Display
  • IoT Web Dashboard

🏗️ Architecture / BIM
2025 ✓ Completed

Building Information Modelling (BIM)

🏛️ Engineering Project — Adichunchanagiri Institute of Technology (AIT)

Developed a comprehensive 3D digital building model that unifies architectural layout, structural frame, and MEP (Mechanical, Electrical, Plumbing) systems into a single coordinated data model. The BIM workflow enables automatic clash detection between subsystems, parametric cost estimation, and full lifecycle management from design through demolition.

Key Features & Outcomes

  • 🏛️ 3D integrated model: architecture + structure + MEP in one file
  • ⚡ Automated clash detection — identified 40+ design conflicts pre-construction
  • 💰 Parametric cost estimation linked to BIM element quantities
  • 🔄 Python scripts for automated drawing sheet generation
  • 📐 Floor plans, sections, and elevations auto-generated from 3D model
  • 📉 ~40% reduction in design rework and revision cycles

Technology Stack

  • Autodesk Revit
  • AutoCAD
  • BIM 360
  • Python Automation
  • Navisworks (Clash Detection)
  • MEP Coordination
  • Structural Analysis
